How a quiz runs

The same loop every time, so the feedback is something you act on rather than a grade you file away.

  1. Teacher

    Picks the questions

    From 127 Paper 1, 2 and 3 style questions, then shares a code with the class.

    K7QM2P
  2. You

    Answer each part

    Type your working and your answer, with a symbol bar for √, π, ≤ and the rest. Drafts save as you go.

    x = ±5
  3. Teacher

    Marks every part

    Correct, partly correct or incorrect, checked against the IB-style markscheme, with a comment where it helps.

    A1  R0
  4. You

    Fix it and resubmit

    The marks appear on your page within seconds. Revise the parts that lost marks and send them back.

    now 5/5
